# Free Will Generator
A web app that generates daily prompts nudging you to break small patterns — what to wear, where to walk, who to text — as a tiny rebellion against autopilot.

Demo: https://github.com/user-attachments/assets/035509aa-cea2-40ee-8690-6aa6aea357ca

# The idea
"Existence precedes essence." This generator encourages you to introduce a small dose of randomness, neuroplasticity, and tiny rebellions against the version of you that woke up this morning.
The prompts push you toward the person you want to become. Some feel like aesthetic changes — but they're meant to build confidence in how you show up, because sometimes the fear of being perceived is the whole thing keeping you stuck.

# How it works
Prompts are drawn from a curated set across categories like style, social, and routine.
